# Dinesh Kumar Birthday Surprise

This is a personalized, mobile-friendly birthday surprise website with all six supplied photos included in an interactive photo gallery.

## Publish using GitHub Pages

1. Sign in at https://github.com.
2. Create a **Public** repository named `dinesh-birthday`.
3. Extract this ZIP file on your phone or computer.
4. Upload **both** `index.html` and the complete `assets` folder to the repository root. Keep the `assets` folder name unchanged.
5. Commit the uploaded files.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main**, folder **/(root)**, then press **Save**.
9. After deployment, your site address will be:
   `https://YOUR-USERNAME.github.io/dinesh-birthday/`

Replace `YOUR-USERNAME` with your GitHub username.

## Edit the birthday message

Open `index.html` and search for the text you want to change, such as `Dinesh Kumar`, `Your Friend`, or the birthday letter.

The six photos are in `assets/`. Do not rename the folder unless you also update the image paths in `index.html`.

No paid hosting, server, or database is needed.
